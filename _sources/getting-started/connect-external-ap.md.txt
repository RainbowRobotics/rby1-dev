# Connect to an External Access Point (AP)

## Wi‑Fi

1. In the Web UI, open **Settings**.

```{image} ../_static/images/getting-started/wifi1.png
   :align: center
   :width: 800px
   :class: white_bg
```

2. Go to **RPC WiFi Setting**. Confirm the Wi‑Fi page and the **Scan WiFi** button are visible.

```{image} ../_static/images/getting-started/wifi2.png
   :align: center
   :width: 800px
   :class: white_bg
```

3. Click **Scan WiFi** and wait for the scanned SSID list to appear.

```{image} ../_static/images/getting-started/wifi3.png
   :align: center
   :width: 800px
   :class: white_bg
```

4. Click **Connect** on your target SSID, then enter the password and choose IP mode (**DHCP** or **Static IP**). Save/apply the settings.

```{image} ../_static/images/getting-started/wifi4.png
   :align: center
   :width: 800px
   :class: white_bg
```
5.  In the Web UI, confirm that the interface is connected and has an IP address.

```{image} ../_static/images/getting-started/wifi5.png
   :align: center
   :width: 800px
   :class: white_bg
```
