# Tutorial Videos

Use these tutorial videos as the first walkthrough before operating RB-Y1.
They show the basic flow for preparing the robot, checking the Web UI,
understanding the hardware, using RPC management tools, and starting SDK-based
development.

```{important}
Before moving the robot, review the safety guidance and keep the E-Stop within
reach. Watch the relevant tutorial video first, then operate RB-Y1 step by step
in a clear workspace with enough room around the arms, body, and mobile base.
```

## Recommended Order

1. **Quick Start Guide** - Follow this first when preparing RB-Y1 for initial operation.
2. **Web UI** - Learn how to access the robot, check status, and use basic controls.
3. **Hardware** - Check the physical components, connection points, and handling notes.
4. **RPC** - Review management tools for maintenance and system-level operations.
5. **SDK** - Continue with SDK installation, state checks, and application development.

After watching the videos, continue with the written setup pages in this section:
[Unboxing](unboxing.md), [Hotspot and Web UI](hotspot-and-webui.md),
[Connect External AP](connect-external-ap.md), and
[SDK Installation and Read State](sdk-install-and-state.md).
