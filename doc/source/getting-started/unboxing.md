# Unboxing

Purpose: verify essentials and place the robot safely.

## Included items (example)
- Mobile base + manipulator (model-specific)
- Controller / power adapter (if applicable)
- E-Stop
- 1× Ethernet cable
- Basic tools / accessories

## First placement
- Use a clear area (~2×2 m).
- Keep cables away from wheels and joints.
- Do not enable torque yet.
