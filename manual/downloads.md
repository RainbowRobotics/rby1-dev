# Downloads

Software and files for RB-Y1, and where to get them.

| What | Where | Notes |
| ---- | ----- | ----- |
| Robot software (robot PC) | [rby1-release releases](https://github.com/RainbowRobotics/rby1-release/releases) | Install with the [RPC Updater](rpc_management_tools/rpc_updater.md). Read the release notes before updating. |
| SDK (Python) | `pip install rby1-sdk` ([PyPI](https://pypi.org/project/rby1-sdk/)) | See [Supported Platforms](getting-started/supported-platforms.md) for Python and OS versions. |
| SDK (C++), examples and robot models (URDF) | [rby1-sdk on GitHub](https://github.com/RainbowRobotics/rby1-sdk) | Build: [C++ Build & Link](sdk/cpp/build-and-link.md). URDF files are in `models/`. |
| ROS 2 driver | [rby1-ros2 on GitHub](https://github.com/RainbowRobotics/rby1-ros2) | [Install & Build](ros2/ros2_driver/install_and_build.md) |
| Simulator (MuJoCo, Docker) | [rainbowroboticsofficial/rby1-sim](https://hub.docker.com/r/rainbowroboticsofficial/rby1-sim/tags) | Pick the tag for your robot model: [MuJoCo](simulators/mujoco.md) |
| LeRobot integration | [rby1-lerobot on GitHub](https://github.com/RainbowRobotics/rby1-lerobot) | Teleoperation and data collection with the leader arm. |
| Maintenance tools (updater, log backup, CAN checker, F/T sensor zeroing, bootloader) | Download links on each tool page under [Maintenance & Tools](maintenance/index.md) | These files are on Rainbow Robotics SharePoint/OneDrive and may ask you to sign in. If a link does not open, contact [support](support.md). |
