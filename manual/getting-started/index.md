# Getting Started

Start here if you have just received an RB-Y1. Read the E‑Stop page first, then follow the numbered steps:
unpack the robot, connect to its hotspot and Web UI, move it onto your network, install the SDK
and make the first motion.

<div class="link-cards">

- [**1. E‑Stop Basics**](estop-basics.md)<br>Stop the robot and recover. Read before the first power‑on.

- [**2. Unboxing**](unboxing.md)<br>What is in the box and how to connect the battery.

- [**3. Hotspot & Web UI**](hotspot-and-webui.md)<br>Power on, servo on, Control Manager and zero pose.

- [**4. External Access Point**](connect-external-ap.md)<br>Move the robot onto your Wi‑Fi network.

- [**5. SDK Installation**](sdk-install-and-state.md)<br>Install the Python SDK and read the robot state.

- [**6. First Motion**](first-motion.md)<br>Move the robot with the SDK examples and test the E-Stop.

</div>
