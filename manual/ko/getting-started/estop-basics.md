# 비상정지(E‑Stop) 기본

## 비상정지 장치
- 종류: 비상정지 버튼, 원격 비상정지(리모컨)

::: warning
제품에는 비상정지 버튼과 리모컨이 함께 들어 있습니다. 둘 다 전원을 차단하는 안전 장치입니다.
자세한 내용은 [차단 방법](../../hardware/electrical_part.md#shutdown-methods)을 참고하십시오.

비상정지 버튼이 눌려 있었다면 작동 전에 원래 위치로 해제해 두십시오.
:::

## 처음 전원을 켜기 전에
처음 전원을 켜기 전에 이 페이지를 읽으십시오. 다음 단계부터 로봇에 전원을 넣고 서보를 켜며 로봇을 움직입니다.

- 첫 시험 동안 비상정지 버튼이나 리모컨을 손에 들고 있으십시오.
- 전원을 켜기 전에 비상정지 버튼이 해제되어 있는지(돌려서 복귀) 확인하십시오.
- 로봇 주변을 비우십시오. 영점 자세 동작에서 몸통과 양팔이 움직입니다.
- 처음 전원을 켠 뒤, 원격 조작·SDK 제어·주행을 하기 전에 비상정지를 한 번 눌러 로봇이 멈추는지 확인하십시오.

[주의사항](../../precautions/general.md)과 [차단 방법](../../hardware/electrical_part.md#shutdown-methods)도 함께 확인하십시오.

## 비상정지를 누르면
- 구동부로 가는 48 V 전원이 차단되고 관절 브레이크가 잠깁니다. 로봇 PC(RPC)는 계속 동작하므로 Web UI와 SDK 연결은 유지됩니다.
- 로봇 상태에 비상정지가 눌린 것으로 표시됩니다(SDK 로봇 상태의 `emo_states`).
- 비상정지가 눌린 동안에는 **POWER ON**이 실패하고, 로그에 `EMO Error: Please check EMO Switch`가 남습니다.

## 비상정지 후 복구
1. 정지 원인을 없애고 로봇 주변이 비어 있는지 확인합니다.
2. 비상정지 버튼을 해제합니다(돌려서 복귀).
3. Web UI에서 전원을 다시 켭니다(**POWER ON**).
4. 서보를 다시 켭니다.
5. Control Manager를 켭니다. 상태가 **Fault**이면 먼저 **Reset**을 누른 뒤 **Enable**을 누릅니다.

전원을 끊지 않고 동작만 멈추려면 Web UI 상단의 **SOFT STOP** 버튼을 사용합니다.
