# Maintenance

Update the robot PC (RPC) software, back up logs, check the hardware, and replace parts.
The tools run on the user PC (UPC) or on another Linux PC and connect to the RPC over the network.

<div class="link-cards">

- [**RPC Updater**](../rpc_management_tools/rpc_updater.md)<br>Update the robot PC software.

- [**Log Backup**](../rpc_management_tools/log_backup.md)<br>Copy logs from the robot PC.

- [**CAN Checker**](../rpc_management_tools/can_checker.md)<br>Check the CAN communication.

- [**FT Sensor Initialization**](../rpc_management_tools/ft_sensor_initialize.md)<br>Set the zero of the wrist F/T sensors.

- [**Bootloader**](../rpc_management_tools/bootloader.md)<br>Motor driver firmware tool.

- [**Parts Detaching**](detaching_guide.md)<br>Detach and attach the arm, wrist module, gripper and F/T sensor.

</div>
