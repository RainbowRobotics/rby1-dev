# Support

## Where to ask

| Question or problem | Channel |
| ------------------- | ------- |
| Questions about using the robot, the SDK or ROS 2 | [rby1-sdk GitHub Discussions](https://github.com/RainbowRobotics/rby1-sdk/discussions) |
| A bug in the SDK (wrong behavior, crash, wrong documentation in the API) | [rby1-sdk GitHub Issues](https://github.com/RainbowRobotics/rby1-sdk/issues) |
| A bug in the ROS 2 driver | [rby1-ros2 GitHub Issues](https://github.com/RainbowRobotics/rby1-ros2/issues) |
| A mistake in this manual | [rby1-dev GitHub Issues](https://github.com/RainbowRobotics/rby1-dev/issues), or use "Edit this page on GitHub" at the bottom of the page |
| Hardware faults, repairs, firmware, anything that needs your robot's serial number | E-mail <code>rby.support@rainbow-robotics.com</code> |

## What to include

Send what we need to reproduce the problem:

- Robot model and hardware version (for example, Model A v1.2), robot software version, SDK version (`pip show rby1-sdk`).
- What you did, what you expected, and what happened, step by step.
- Robot logs from the time of the problem: see [Error Reporting](sdk/troubleshooting/generated/error_reporting.md) and [Log Backup](rpc_management_tools/log_backup.md).
